# 🇯🇵 カタカナクイズ - 日本語学習アプリ

カタカナの読み方を楽しく練習できるインタラクティブなWebアプリです。  
HTML、CSS、JavaScriptのみで作られています。

## 特徴
- ランダムなカタカナを表示（濁音・半濁音含む）
- 4択クイズ形式
- 正解数・連続正解数をトラッキング
- スマホ対応のレスポンシブデザイン
- 英語／日本語のフィードバック

# 🇯🇵 Katakana Quiz – Japanese Learning App

A fun, interactive web app to practice reading **Katakana**.  
Built with vanilla HTML, CSS, and JavaScript. Perfect for Japanese learners!

## Features
- Random katakana characters (including dakuten/handakuten)
- Multiple-choice answers
- Score & streak tracking
- Responsive design (mobile friendly)
- Bilingual interface (English / Japanese feedback)
